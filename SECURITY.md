# Sicherheitsrichtlinie

Hast du eine Sicherheitslücke in SkillMatcher gefunden? Bitte melde sie **nicht öffentlich** (kein Issue),
sondern per E-Mail an die im Impressum genannte Kontaktadresse bzw. über GitHub →
Security → „Report a vulnerability". Wir antworten zeitnah und bitten um Vertraulichkeit, bis ein Fix verfügbar ist.

Hinweise zur Konfiguration und zum Betrieb: [docs/hardening-checklist.md](docs/hardening-checklist.md).
